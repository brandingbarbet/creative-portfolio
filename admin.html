Portfolio Control Room

Manage your website content, navigation, projects and images.

Admin sign in

Use the admin email and password you created in Supabase Authentication.

Public sign-ups should remain disabled in Supabase. Admin access is controlled by the portfolio admin allowlist.

Connect Supabase first

Open config.js and add your Supabase project URL and anon/publishable key. Do not use the service-role key in frontend code.

Changes are local until saved.

Site settings

Brand, hero, colors, contact details and social links.

Navigation

Add, rename, remove or reorder the top navigation links.

Page sections

Control section order, visibility, text, type and images. New sections can be linked to the navigation.

Portfolio projects

Each project appears in sections whose type is “Projects”. Upload images directly to Supabase Storage.

Remember to save after editing.
Static frontend · Supabase Auth, Database and Storage · Never share your password or service-role key.
